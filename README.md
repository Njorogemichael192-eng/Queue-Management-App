# Queue Management App

A simple queue management mobile application built with Flutter, Dart, and SQLite.

## Features

- Add a person to the queue
- Display waiting people
- Serve the next person
- Mark people as served
- Delete served people
- View queue statistics
- Calculate waiting and served percentages
- Store data locally using SQLite

## Technology

- Flutter
- Dart
- SQLite
- sqflite
- path

## Development

The project is developed using GitHub Codespaces with Flutter SDK, Android SDK, and Android Build Tools.

Development and Android APK builds will be performed in the cloud.
